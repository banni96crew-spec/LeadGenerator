# АТРИУМ — премиум-строительный лендинг

Статический сайт продажи частных домов под ключ.

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
npx serve .
```

## Стек

- Static HTML / CSS / минимальный JS
- Шрифт Onest (заголовки 800, UI 400/600)
- Photoreal assets в `assets/`
