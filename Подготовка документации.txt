# Полный каталог Rules и Skills для LeadGenerator

Ниже — **целевой набор** для всей системы из `PRD.md`. Уже есть только `00-project-overview.mdc`; остальное — к созданию по milestone.

---

## Принцип разбиения

| Тип | Назначение | Когда срабатывает |
|-----|------------|-------------------|
| **Global rule** | Инварианты всей системы | `alwaysApply: true` |
| **Scoped rule** | Один слой/стадия | `globs` по путям |
| **Agent rule** | Поведение LLM-стадии | `globs: agents/{name}/**` |
| **Skill** | Повторяемая процедура (код/MCP/CLI) | Агент вызывает по описанию задачи |

**Правило:** overview = конституция; scoped/agent rules = детали; skills = «как выполнить», не «как думать».

## Что НЕ нужно как отдельные rules/skills

| Идея | Почему не отдельно |
|------|-------------------|
| Screenshot Agent | Входит в `capture-step.mdc` + `capture-website` |
| GitHub Publish Agent | Входит в `publish-step.mdc` + `deploy-cloudflare` |
| «Сбор данных» agent | Часть Capture или Research |
| Отдельный skill на каждый JSON-файл | Один `validate-contract` + схемы в `schemas/` |
| Skill на каждый gate | Можно 6 мелких (S8–S11 + G3/G4/G6) или один `run-quality-gate` с параметром `gate_id` — на выбор при реализации |
